Fonts bundled with the game (all SIL Open Font License 1.1, licences beside them):

- manrope-latin.woff2: Manrope, Copyright 2019 The Manrope Project Authors,
  https://github.com/sharanda/manrope, the Latin subset of the variable font
  (weights 200 to 800) as published by Fontsource (@fontsource-variable/manrope
  5.3.0). It sets running text, labels and captions.
- bangers-latin.woff2: Bangers, Copyright 2010 The Bangers Project Authors,
  https://github.com/googlefonts/bangers, subset to Latin-1 plus a few
  punctuation marks and arrows.
- yuji-boku-kanji.woff2: Yuji Boku, Copyright 2021 The Yuji Project Authors,
  https://github.com/Kinutafontfactory/Yuji, subset to the 16 kanji the menus
  draw: 火風水雷土暁忍爆影勝敗術道場里巻.

Bangers and Yuji Boku were subset with fontTools (pyftsubset) to WOFF2.
Neither is the show's logo face.
